# Koubou 0.20.0 for screenshot framing

`asc screenshots frame` now pins Koubou 0.20.0 instead of 0.18.1. Other
Koubou versions are rejected as unsupported; an older install gets an upgrade
hint. Upgrade and refresh the downloaded frames:

```bash
pip install -U koubou==0.20.0   # or: brew upgrade bitomule/tap/koubou
kou setup-frames
```

Frames generated by asc look the same after the upgrade. The frame artwork is
unchanged, and asc now emits `alignment: center` on every generated image item
as well as on text, so Koubou 0.19.0's alignment change keeps them centered.

Custom `--config` YAML files may need updates:

- Koubou 0.19.4 removed `"` from 18 frame names, for example
  `iPad Air 13" - M2 - Space Gray - Portrait` is now
  `iPad Air 13 - M2 - Space Gray - Portrait`.
- Koubou 0.19.0 made content `alignment` the true horizontal anchor for text
  and images. Items with `alignment: left` or `right` now start or end at their
  `position` x value.
